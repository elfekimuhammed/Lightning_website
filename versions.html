How an update is archived

Before changing a live experience, copy its current page to archive/RELEASE-ID.html, add that URL to the registry, mark it Archived, then assign the changed live page a new UX-YYYY.MM.DD.NN ID. This keeps the old version reachable by its visible ID and makes feedback comparable across releases.
